What each section does

Keyboard shortcuts

Single-key shortcuts are ignored while you're typing, and while a game is running — a stray keypress after an iframe loses focus would otherwise navigate you out of the game. The admin combo uses a modifier precisely so it still works mid-game. All of them can be switched off in Settings.

Ranks

Ranks are ordered, not a list of flags. The rule everywhere is the same: you can only act on someone below you, and you can never promote anyone to your own rank. The server enforces this — hiding a button here is convenience, not security.
